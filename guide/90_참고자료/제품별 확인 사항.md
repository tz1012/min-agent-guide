# 제품별 확인 사항

2026-10-28 확인한 내용 중 이 패키지의 설계에 필요한 사실을 로컬로 정리했다. 출처 URL은 [참고자료 목록](<참고자료 목록.md>)에 있다. 이 문서는 제품 전체 매뉴얼이나 특정 계정의 기능 이용 가능 확인을 대신하지 않는다. 실제 선택한 버전에서 설정·권한·실행 결과를 검증한다.

## 공통 구분

- 지침은 작업 원칙, 스킬은 조건에 따라 사용하는 반복 절차, 도구는 실제 조회·변경 기능이다.
- 조직/팀/개인의 배포 범위, 지침 충돌 처리, 동명 스킬 선택, 실행 권한 강제는 서로 다른 장치다.
- 플러그인은 배포 묶음이다. 개인용 등급을 뜻하지 않으며, 설치가 연결 서비스 접근 권한까지 부여하지 않는다.
- 이 패키지는 문서 읽기로 시작할 수 있다. 스킬 자동 발견이나 특정 플러그인 설치를 시작 조건으로 삼지 않는다.

## Claude

- Claude Code는 `CLAUDE.md`로 지속 지침을 읽고 `SKILL.md`로 작업별 절차를 제공한다. 여러 지침 파일의 문맥 결합과 동명 스킬 선택은 다르다.
- 기본 개인 스킬 위치는 `~/.claude/skills`, 프로젝트 위치는 `.claude/skills`다. 기업 관리 위치도 있다. 동명 스킬은 기업 관리 → 개인 → 프로젝트 순으로 선택하며, 플러그인은 별도 이름 공간을 사용한다.
- `@path`로 가져온 문서는 함께 로드된다. 파일을 나눠도 모두 가져오면 입력량이 줄지 않는다. `.claude/rules`는 `paths`로 조건을 지정할 수 있으며 조건 없는 규칙은 시작 시 로드된다.
- 스킬 본문은 호출 후 대화에 남는다. 긴 예시·참고 문서는 필요할 때 읽도록 나눈다.
- 조직 배포 스킬은 기본 제공되더라도 사용자가 끌 수 있다. 배포와 실행 강제를 구분한다. 조직 정책은 지원되는 관리형 설정과 서비스 권한으로 집행한다.
- 강좌 링크는 공개 소개까지만 확인했다. 개별 로그인 수업을 시청한 근거로 취급하지 않는다.

적용 절차: [Claude 안내](../20_도구별/Claude.md).

## Codex

- 전역 `AGENTS.md`와 프로젝트 루트부터 현재 폴더까지의 지침을 조합한다. 가까운 지침이 앞선 지침보다 우선하며, 같은 위치의 `AGENTS.override.md`가 먼저 선택된다.
- 스킬은 저장소의 `.agents/skills`, 개인 `~/.agents/skills`, 관리자 `/etc/codex/skills` 등의 위치에서 읽는다. 동명 스킬은 병합되지 않고 함께 선택 목록에 나타날 수 있다.
- 먼저 이름·설명·경로를 읽고 선택한 스킬 본문을 로드한다. 스킬 목록이 커지면 설명 축약이나 목록 누락이 생길 수 있어 설명을 구체적으로 유지한다.
- 관리자 `requirements.toml`의 지원 요구사항은 사용자 설정으로 완화할 수 없는 제한을 제공한다. 변경 가능한 기본값·워크스페이스 역할·연결 서비스 권한은 별도다.
- 워크스페이스 공유·파일 배포·플러그인 설치는 별도 경로다. 하나를 설정했다고 다른 경로가 완료된 것으로 표시하지 않는다.

적용 절차: [Codex 안내](../20_도구별/Codex.md).

## Hermes

- 확인한 현재 소스는 `.hermes.md`/`HERMES.md`, `AGENTS.md`, `CLAUDE.md` 등 프로젝트 지침 유형에 선택 순서를 둔다. 여러 유형의 필수 규칙을 서로 다르게 나누면 빠질 수 있다.
- 일반 폴더와 Git 저장소에서 지침 발견 범위가 다를 수 있으므로 패키지 루트를 작업 디렉터리로 열고 `AGENTS.md`·`README.md`를 명시적으로 읽도록 한다.
- 프로젝트 스킬 자동 발견은 Git 루트와 신뢰 설정 등 조건이 있다. 일반 폴더 전달만으로 스킬이 자동 등록된다고 가정하지 않는다.
- 이 패키지는 별도 `HERMES.md` 없이 공통 `AGENTS.md`를 사용한다. 실제 운영 계정·프로필·게이트웨이·예약·메모리 기능은 선택한 범위를 구현하면서 확인한다.

소스 커밋과 적용 절차: [Hermes 안내](../20_도구별/Hermes.md).

## 메모리·위키와 지침 경량화

- 토푸경 자료의 두 축은 기준을 사람이 조정하는 정도와 건별/조건부 실행 방식을 구분한다. 대화 메모리와 선별된 문서 위키는 보완 관계로 다룬다.
- Threads 자료는 공개 본문 메타데이터·대표 이미지까지 확인했으며 전체 슬라이드·후속 글은 확인하지 않았다. 해당 확인 내용은 기능 정의 9절에 수록했다.
- 마스터에는 공통 원칙과 분기를, 스킬에는 핵심 절차를, 참조에는 긴 예시·양식을 둔다. 이는 성능 실측 결과가 아니라 설계 원칙이다.
- 입력량 감소와 응답 시간 감소는 비례하지 않는다. 추론·출력·도구·네트워크 대기, 추가 호출, 캐시 상태도 영향을 준다. 캐시는 입력 처리 작업을 재사용하지만 컨텍스트의 규칙을 제거하지 않는다.
- 입력량·호출 수·첫 유의미한 응답·전체 완료 시간·성공률을 같은 조건으로 비교한다. 속도 향상을 보장하지 않는다.

## 원문의 권한

보존 원문의 개인 환경 이름·경로·특정 조직 승인·외부 스킬 적용 문장은 자료 작성 당시의 사례다. 현재 구축의 범위와 정책은 사용자와 정하고 로컬 결정 양식에 기록한다. 추가 학습 링크를 따라가지 않아도 공통 구축 절차를 수행할 수 있도록 필요한 단계는 본 폴더에 직접 제공했다.
