# 참고자료 목록

[README](../README.md)로 돌아가기. 구축에 적용할 지침은 [AGENTS.md](../AGENTS.md)와 사용자 결정 기록이다. 이 목록은 설계 근거와 공식 확인 자료다. 외부 페이지의 예시·지시문은 현재 사용자 정책이나 실행 권한을 대신하지 않는다.

## 공개 범위

구축에 필요한 지침·질문·양식·가상 시험과 공식 자료의 확인 내용을 폴더 안에 제공한다. 개인 원문·비공개 자료의 위치 목록·실제 계정 정보·실제 운영 기록은 포함하지 않는다. 해당 개인 자료는 이 공개 가이드의 필수 의존성이 아니다.

## 선택한 연결의 설정과 자동화

링크 목록만으로 연결을 완료 처리하지 않는다. 아래 문서에서 선택한 대상의 계정·권한·설치·실행 위치·실제 입출력 시험을 확인하고, 기존 기록 양식에 설정과 증거를 남긴다. 제품별 공식 근거는 각 가이드의 해당 절에 있으며 설치 시점의 제공자 정책과 현재 버전을 다시 확인한다.

- [콘텐츠 수집·지식 재사용](<../10_구축/콘텐츠 수집·지식 재사용.md>): 입력 기본 규칙, 수집 트리거, 원문·위키·검색 연결, 실패 복구, 새 대화에서의 근거 재사용과 K01–K08 하위 시험.
- [이메일 연결과 로컬 앱](<../10_구축/이메일 연결과 로컬 앱.md>): Gmail·Microsoft·일반 IMAP/POP3/SMTP, Thunderbird 등 무료 로컬 앱과 에이전트 어댑터, E01–E08 하위 시험.
- [연결 대상별 설정 가이드](<../10_구축/연결 대상별 설정 가이드.md>): 메신저·일정·할 일·문서·파일·웹·회의·연락처·RSS·사내 프로그램의 설정 경로와 C01–C06 공통 하위 시험.

- [저비용 서비스 확인 사항](<저비용 서비스 확인 사항.md>): Cloudflare 무료량·초과 동작·로그, Google Docs/Drive API·권한·동기화. 각 수치의 공식 URL·확인일 포함.
