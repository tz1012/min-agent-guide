# 공개 패키지 점검 기록

이 기록은 공개 `guide/` 폴더의 자료 구성·문서 연결을 점검한 것이다. 개인·기업 시스템의 설치·인증·자동화·운영 결과를 기록한 문서가 아니다.

## 공개 범위

- 진입 안내·기능 정의·구축 절차·도구별 안내·기존 빈 기록 양식 3개·가상 시험·공식 참고자료를 포함한다.
- 개인 원문·비공개 자료의 위치 목록·실제 계정과 인증 정보·채워진 운영 기록·가이드 소유자의 배포 환경 기록은 포함하지 않는다.
- 해당 개인 자료 없이도 질문·설계·구축·검증 절차를 이해하고 진행할 수 있다. 선택한 제품의 설치 자원·계정·인증은 별도로 필요하다.

## 문서 검사

2026-10-28 공개판의 파일 구성, YAML, 상대 링크, F/D/S/V 식별자와 초기 상태, 가상 시험 JSON, 개인 식별·경로·배포 정보 패턴을 검사했다.

| 항목 | 결과 |
| --- | --- |
| 공개 구축 자료 | 28개 — Markdown 27개, 가상 시험 JSON 1개. 배포 시 파일별 SHA-256 매니페스트 1개를 추가하므로 ZIP에는 29개 파일이 포함됨 |

| 비공개 의존성 | 개인 Sheets/Drive 링크, 로컬 절대 경로, 배포 ID, 비공개 원문 경로 없음 |

## ZIP만 받은 상태의 시작 점검

공개 ZIP을 별도 임시 폴더에 풀고 기존 대화·비공개 볼트 없이 README → AGENTS → 셋업 절차와 기록 양식으로 진행할 수 있는지 문서상 대조했다. 로컬 CLI와 기존 파일 재사용, 휴대폰만 사용하며 집 실행기가 꺼진 경우, 회사 자료를 외부로 내보낼 수 없는 경우 모두 필요한 분기·대기·저장·재개 안내를 확인했다. ZIP의 28개 자료는 매니페스트의 크기·SHA-256과 일치했고 누락·중복·경로 탈출·해결되지 않는 내부 파일 링크가 없었다. 기본 설계 방향은 각 사용자의 실제 선택·승인과 구분한다.

## 검증하지 않은 범위

가상 시험은 입력과 기대 결과만 제공하며 아직 실행하지 않았다. 제품 설치·사용자 인증·실제 서비스 연결·모델 실행·모바일 접속·권한 집행·백업 복구·부하·비용 집행은 이 공개 패키지 검사에 포함하지 않았다. 실제 대상에서는 [초기 셋업 흐름](<../10_구축/초기 셋업 흐름.md>)에 따라 필요한 범위를 구현하고 [검증·운영 기록](<../30_양식/검증·운영 기록.md>)에 관찰 증거를 남긴다.
